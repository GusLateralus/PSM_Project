# Arduino Mega

En ésta sección, se incluyen los códigos de Arduino IDE para los sensores que utiliza el Arduino Mega en este proyecto. 
Se incluyen los sensores DHT11, MQ135 y los módulos RTC DS3231 y SD Card. 

## Nota

En caso de utilizar estos códigos, es necesario descargar el archivo principal **.ino** y sus módulos **.h**, 
los cuales deben permanecer en la misma carpeta que el archivo principal para un correcto funcionamiento.
